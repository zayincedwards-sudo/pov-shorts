Privacy policy

Last updated 25 August 2026

pov-shorts is a personal automation tool operated by one person for their own YouTube channels. It has no other users, no accounts, no sign-up, and no server that receives data. This policy describes what the tool touches and where it goes.

What is collected

Nothing is collected from anyone. The tool has no visitors and no customers. It does not gather personal information from any third party, and it has no analytics, tracking, advertising, or telemetry of any kind.

Google account data the tool uses

When the operator signs in, Google issues an OAuth token for a single YouTube channel that the operator owns. The tool requests two permissions:

  • youtube.upload — to publish a video to that channel.
  • youtube.force-ssl — to read back which channel the token belongs to, so an upload cannot silently land on the wrong channel.

These tokens are written to files on the operator's own computer and are used only to upload video to the operator's own channels. They are never transmitted to any third party, never uploaded anywhere, and are not shared, sold, or disclosed.

The tool also reads public view counts for the operator's own published videos, using a Google API key. That data is public and concerns only the operator's channels.

What the tool does not have access to

The permissions above do not grant access to YouTube Analytics. The tool cannot read watch time, audience retention, demographics, subscriber identities, or traffic sources. It cannot read private videos, comments, or messages, and it cannot access any channel other than one the operator has explicitly signed in to.

Source video

The tool searches publicly listed YouTube videos and downloads short excerpts to the operator's computer for editing. No personal data about the uploaders or viewers of those videos is extracted, stored, or transmitted.

Retention and deletion

All data — tokens, downloaded clips, and rendered video — lives on the operator's own computer and is deleted by deleting those files. The operator can revoke the tool's access at any time at myaccount.google.com/permissions, which immediately invalidates the stored tokens.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used solely to upload video to the operator's own channels and is never used for advertising, never sold, and never transferred to others except as required by law.

Changes

If this policy changes, the date above changes with it.
